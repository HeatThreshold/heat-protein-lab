# references.md

Running bibliography for every claim that appears in the UI. Each chapter that lands adds its citations here in addition to inline UI links. Citations should be the *primary source* when possible (peer-reviewed paper, structure deposition, database entry), not Wikipedia.

Format per entry:
```
- **Short label** — Full citation. URL or DOI. Retrieved YYYY-MM-DD. (Used in: Ch N)
```

## Upstream data sources (umbrella attributions)

The following are the public databases the project queries. License acknowledgment files (`LICENSE_NOTIFICATION.txt`) are stored in each Science Skill's directory under `~/.gemini/config/plugins/science/skills/`, not in this repo.

- **RCSB Protein Data Bank (PDB)** — https://www.rcsb.org — usage policy at https://www.rcsb.org/pages/usage-policy
- **AlphaFold Protein Structure Database (EBI)** — https://alphafold.ebi.ac.uk
- **Human Protein Atlas (HPA)** — https://www.proteinatlas.org — license at https://www.proteinatlas.org/about/licence
- **NCBI PubMed / PMC** — https://pubmed.ncbi.nlm.nih.gov — disclaimer at https://pubmed.ncbi.nlm.nih.gov/disclaimer/
- **NCBI ClinVar** — https://www.ncbi.nlm.nih.gov/clinvar/
- **NCBI dbSNP** — https://www.ncbi.nlm.nih.gov/snp/
- **Reactome** — https://reactome.org — license at https://reactome.org/license, citation guide at https://reactome.org/cite
