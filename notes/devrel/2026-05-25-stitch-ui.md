## Surprises

- **Subprocess concurrency:** We discovered that since Stitch MCP runs as a remote endpoint over JSON-RPC via `npx mcp-remote`, we could trigger multiple concurrent subprocess requests using python's `threading`. Kicking off all 9 mockup generations in parallel reduced total processing time from over 15 minutes to under 2 minutes.

## Frustrations / sharp edges

- **Context limits on long lines:** Base64-encoding `DESIGN.md` in one line resulted in truncation in the chat window, preventing easy manual copying. We resolved this by wrapping the output at 76 columns and saving it to a file.
- **Nested JSON paths:** The response from `generate_screen_from_text` returned the created screen's meta nested deeply within `outputComponents[0]["design"]["screens"][0]`. Standard extraction for `id` failed initially until we ran a raw test script to dump and inspect the JSON structure.
