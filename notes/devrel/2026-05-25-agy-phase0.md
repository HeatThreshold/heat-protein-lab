## What was attempted

Use `agy --print --dangerously-skip-permissions` (the CLI version of Antigravity, distinct from the desktop IDE used in the first session) to run the six Phase 0 smoke tests from PROJECT.md against the live science databases, write the verified IDs to `data/candidates.json`, and create LICENSE_NOTIFICATION.txt files in each skill directory.

## How it was driven

Initial attempt: one mega-prompt asking agy to do all six skills sequentially and synthesize the JSON. **It stalled.** PID 3230380 ran 14+ minutes at 0.0% CPU, never spawned a single `uv` subprocess, never wrote anything to disk. Process was sleeping on one network socket — appeared to be in an LLM call that never returned a tool invocation. Killed via `pkill`.

Pivot: one focused prompt per skill, run in parallel as five sibling bash calls (after a single-skill PDB test confirmed the pattern worked). Each prompt was 3–5 sentences, included the exact `uv run` command to execute, and capped the response at "under 5 lines." Total wall-clock for the five parallel skills: about 4 minutes. The PDB pilot took roughly 30 seconds.

**Why this matters for Beat 1:** there's a real lesson in there — when prompting an agentic IDE, smaller and more direct prompts converge much faster than orchestration prompts. The instinct to "let it plan the whole thing" cost 15 minutes of nothing; "do one thing, here's the exact command" produced verified output in 30 seconds.

## Surprises

- **The "do everything" prompt failed, the "do one specific thing" prompts all succeeded.** This is probably the most important paragraph the Beat 1 post can publish about agentic IDE prompting — be specific, be small, run in parallel where independent.
- **agy is willing to patch upstream plugin scripts to make things work.** It edited `~/.gemini/config/plugins/science/skills/human_protein_atlas_database/scripts/hpa_cli.py` in place to fix the ValueError. That's both impressive (it didn't give up) and worth flagging (the operator now has a divergent local copy of an upstream skill script, which will conflict with any plugin update).
- **All six skills returned verifiable, citable, useful biology.** The page can now anchor real chapters in real data without anyone hand-typing accession numbers.

## Frustrations / sharp edges

- The 14-minute stall on the mega-prompt was opaque from outside — `ps` showed 0.0% CPU, no spawned subprocesses, nothing in stdout, just one open socket. Without `pkill` access this would have been hard to debug.
- agy copied a 31 KB version of `reactome_analysis.py` into `scripts/` with hardcoded local paths and modified imports. Not portable — anyone cloning the repo on a different machine would have broken paths. Deleted from this commit; future Reactome work should be a small project-specific wrapper, not a vendored copy of the skill script.
- The 951 KB AlphaFold PAE matrix is heavy for git; kept it in `/tmp/` rather than committing. Future fetcher scripts should leave PAE in a non-committed location and only commit metadata + .cif.
